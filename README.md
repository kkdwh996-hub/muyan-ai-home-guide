# 慕言 AI 家电顾问

面向家电电商的语音优先智能导购与客服 Web 项目，依据 `AI案例分析与综合报告.pptx` 中的智能客服、智能导购、适老化语音、可信问答与转人工场景实现。

## 运行

项目无第三方运行时依赖，Node.js 20 以上即可启动：

```powershell
node server.mjs
```

打开 `http://localhost:4173`。执行测试：

```powershell
node --test
```

## GitHub Pages 部署

GitHub Pages 是静态托管，不能运行 Node.js 服务。项目提供了静态构建模式，会把问答引擎一并打包到浏览器中，语音识别、回答生成、商品推荐、对比和播报仍可在前端完成。

本地检查静态版本：

```powershell
node scripts/build-static.mjs
python -m http.server 8080 --directory dist
```

打开 `http://localhost:8080`。将项目推送到 GitHub 仓库的 `main` 分支后，仓库中的 GitHub Actions 工作流会自动构建 `dist` 并部署到 Pages。首次部署时，在仓库的 `Settings > Pages > Build and deployment` 中选择 `GitHub Actions`。

静态部署不会包含真实的人工坐席后端，转人工流程会以浏览器内演示工单运行。生产环境如需真实坐席、订单查询和服务端日志，可将 `server.mjs` 部署到支持 Node.js 的平台，再配置同一域名或跨域接口。

## 已实现的语音回答链路

1. 点击页面中的麦克风，申请浏览器麦克风权限并开始实时转写。
2. 识别结束后自动发送问题，不需要再次点击发送。
3. 后端完成预算、家庭人数、品类和偏好槽位识别，再检索商品与售后知识库。
4. 回答以文字、商品卡和知识来源同步呈现。
5. 浏览器语音合成自动朗读答案，支持暂停、继续、重播和停止。
6. 播报过程中再点麦克风会立即打断播报，并开始下一轮语音提问。
7. 支持多轮上下文、商品参数对比、大字模式和转人工工单。
8. 对麦克风拒绝、未听到声音、识别失败、服务异常和语音合成不可用均提供文字兜底与明确提示。

语音识别与合成使用 Web Speech API。建议使用最新版 Chrome 或 Edge，并通过 HTTPS 或 `localhost` 访问。不同系统可用的中文音色数量会不同。

## 演示问题

- 三口之家，预算四千以内，想买一台省电静音的冰箱
- 把前两款做个对比
- 洗烘一体机和单独洗衣机有什么区别
- 空调安装和退换货政策是什么
- 冰箱不制冷了，怎么处理
- 帮我转人工

商品、价格和服务政策为课程演示数据，不代表真实品牌报价。本地 Node 版本提供工单 API，GitHub Pages 静态版本提供完整的前端演示状态。
